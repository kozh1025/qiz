刑法基本概念

罪刑法定原則

刑法刑§1：行為之處罰，以行為時之法律有明文規定者為限。拘束人身自由之保安處分，亦同。

先有法才有罪：行為當下沒有明文規定處罰，就不能事後用新法回頭處罰（罪刑法定＋禁止溯及既往）。

犯罪之主觀構成要件－故意與過失

類型條文定義
直接故意刑§13Ⅰ對構成犯罪之事實，明知並有意使其發生
間接故意刑§13Ⅱ預見其發生而其發生並不違背本意（放任發生）
無認識過失刑§14Ⅰ應注意、能注意而不注意
有認識過失刑§14Ⅱ雖預見其能發生，但確信其不發生
故意看「有無認知＋有無意欲」；過失看「有無預見＋有無注意」。貪污瀆職罪多數為故意犯，過失原則上不罰（除刑§132Ⅱ洩密罪有處罰過失）。

阻卻（排除）違法事由

事由條文要點
正當防衛刑§23對現在不法侵害，防衛自己或他人權利之行為不罰；過當得減輕或免除其刑
緊急避難刑§24避免自己或他人生命身體自由財產之緊急危難不罰；過當得減輕或免除；公務上業務上有特別義務者不適用避免自己危難之規定
依法令之行為刑§21Ⅰ依法令之行為，不罰
依上級公務員命令之職務行為刑§21Ⅱ不罰；但明知命令違法者不在此限
業務上之正當行為刑§22不罰
貳

貪污瀆職罪之行為主體

公務員之定義與三類型

公務員定義刑§10Ⅱ：①依法令服務於國家、地方自治團體所屬機關而具有法定職務權限，及其他依法令從事公共事務而具有法定職務權限者。②受國家、地方自治團體所屬機關依法委託，從事與委託機關權限有關之公共事務者。

類型取得方式例子排除情形
身分公務員因具一定身分而取得（服務於國家/地方自治團體所屬機關）一般機關承辦人員技工、司機、工友（無法定職務權限）；公營事業/公立學校/公立醫院人員不算身分公務員
授權公務員因法令明定而取得，涉及公權力行使事項更生保護會人員、律師懲戒委員會委員、政府採購法承辦人員-
委託公務員主管機關依法令「得」授權，訂立委託契約，受任範圍內得行使公權力受委託代為驗車之民營汽車公司、代驗排氣之機車行員工單純民事委任（如代收稅款之金融機構員工）非委託公務員；行政助手（如拖吊業者）亦非委託公務員
口訣：身分看「機關」、授權看「法令」、委託看「契約」。行政助手（不以自己名義行使公權力）永遠不是公務員！

貪污治罪條例適用刑法公務員定義：貪§2公務員犯本條例之罪者依本條例處斷；貪§19本條例未規定者適用其他法律規定。

貪污治罪條例三級刑度總表

貪污治罪條例依刑度分三個層級，罪名分散在§4／§5／§6，考試常考「這行為屬於哪一條」，先記刑度分級再記款次最有效率：

條文刑度涵蓋行為（款次濃縮）
貪§4Ⅰ無期徒刑或10年以上，併科1億元以下罰金①竊取侵占公用公有財物 ②藉勢藉端勒索勒徵強占強募財物 ③經辦公用工程浮報價額數量收回扣舞弊 ④公用運輸工具裝運違禁品漏稅物品 ⑤違背職務受賄（①-④未遂犯罰之）
貪§5Ⅰ7年以上，併科6千萬元以下罰金①意圖得利擅提截留公款或違法收募稅捐公債（違法徵收） ②利用職務機會詐術使人交付財物 ③不違背職務受賄（①②未遂犯罰之）
貪§6Ⅰ5年以上，併科3千萬元以下罰金①意圖得利抑留不發應發財物 ②募集款項/徵用土地財物舞弊 ③竊取侵占職務上持有之非公用私有財物 ④主管監督事務圖利 ⑤非主管監督事務圖利（①-③未遂犯罰之）
口訣：4最重（無期/10年,1億）→5次之（7年,6千萬）→6再次（5年,3千萬）。數字愈小、刑度愈輕！

其他特別法（例）：妨害兵役治罪條例、懲治走私條例、組織犯罪防制條例、洗錢防制法、毒品危害防制條例、藥事法、國有財產法等，均有針對公務員包庇/圖利/洩密等加重處罰規定。

賄賂罪

類型／行為態樣／客體／情狀 📌 111,113年考過

類型條文刑度
違背職務受賄罪貪§4Ⅰ⑤無期徒刑或10年以上，併科1億元以下
不違背職務受賄罪貪§5Ⅰ③7年以上，併科6千萬元以下
準受賄罪刑§123尚未為公務員時預先要求期約收受，事後就任履行者，論以受賄罪

行為態樣3種：要求（單方表示，不問明示暗示、對方是否承諾）／期約（雙方合意約定交付）／收受（實際收取或享用，不問先後或主被動）－三者有其一即成立，不以實際取得為要件。

客體2種：賄賂＝金錢或能用金錢計算之財物／不正利益＝賄賂以外一切足以滿足需求慾望之有形無形利益（免除債務、無息貸款、晉升官階、招待旅遊等）。不問數額或經濟價值高低。

行為情狀：違背職務＝應為而不為、不應為而為、執行不當；不問是否「因而為」違背職務之行為，均構成賄賂罪。

賄賂與餽贈之區別

賄賂餽贈
與職務關係基於特定/具體職務收受，與職務行為具對價關係與特定/具體職務行為無關，合社會相當性
法規依據-須符合《公務員廉政倫理規範》第5點：市價超過正常社交禮俗標準應拒絕或退還，或於受贈3日內簽報長官並知會政風
法律效果成立賄賂罪（貪污治罪條例）如有不當，僅依《公務員服務法》受行政處分
假借年節/生日名義送禮，若實質上是為了特定職務行為而給付，名為餽贈仍論賄賂！

案例速記：殯儀館收費紅包／移民署收賄

殯儀館公務員A、B每具遺體收600~1000元紅包配合處理業者時程 → 不違背職務受賄罪（貪§5Ⅰ③）。移民署科員A收賄偽造訪談紀錄讓逾期外籍人士免到案 → 違背職務受賄罪（貪§4Ⅰ⑤）＋行使公務員登載不實文書罪＋行使偽造公文書罪（數罪併罰）。

📌 113年考過 消防小隊長甲執行安全設備複查業務，收受管理權人3萬6千元紅包欣然收受，事後遭檢舉，偵查中坦承並繳回款項 → 先辨是否違背職務（適用貪§4Ⅰ⑤或貪§5Ⅰ③），再答減免規定：偵查中自白＋自動繳回全部所得 → 依貪§8Ⅱ減輕其刑（注意「自首」與「偵查中自白」效果不同，見捌章）。

伍

違背職務罪

圖利罪（主管 vs 非主管） 📌 112,114年考過（最核心考點）

對於主管或監督之事務對於非主管或監督之事務
條文貪§6Ⅰ④貪§6Ⅰ⑤
要件關鍵字直接或間接圖利利用職權機會或身分圖利
刑度5年以上，併科3千萬元以下同左

主管事務＝依法令對事務有主持參與執行之權責（多為承辦人）／監督事務＝非直接執行但有監督權（股長課長科長局處長等）／直接圖利＝行為人直接使自己或第三人得利／間接圖利＝以迂迴方式（如由親友出面經營相關商業）獲利。

主觀要件：必須「明知違背法律等規定」才成立圖利罪＝直接故意；裁量濫用/逾越可能構成，裁量怠惰則個案判斷。

📌 114年考過 常與圖利罪相伴：刑法刑§213公務員登載不實文書罪——複查、稽查、驗收人員明知不實仍登載於職務上所掌公文書（如複查紀錄表登載「已改善」），使相對人得以免罰或獲利，通常同時成立圖利罪＋登載不實罪，兩罪並列論述、數罪併罰，切勿只答一罪。

考古題示意：114年Q4圖利罪＋登載不實

消防隊員甲複查乙之消防設備，發現缺失未改善且逾期，因與乙為好友，未開舉發單並登載「已改善」致乙免罰 → 違背應舉發之義務使乙獲不法利益＋登載不實 → 貪§6Ⅰ④圖利罪＋刑§213登載不實文書罪；若乙確已改善僅逾期陳報而據實登載，則屬便民。查看114年完整申論題解析 →

圖利與便民之分際 📌 112,114年考過（幾乎固定考法）

圖利（違法）便民（合法）
是否違背法令違背法律等規定依法行政、在法令許可範圍內
主觀意圖明知違背仍圖利（直接故意）沒有為自己或他人圖取不法利益之故意及意圖
人民所得不法利益合法利益，只是在手續或程序上給予人民方便
唯一判斷標準：有無違背法律等法令規定。都是給利益，差別在「合不合法」。112年考古題：明知丙非合辦單位仍登記為「合辦單位」使免費使用 → 違背規定使獲不法利益 → 圖利罪。114年考古題：消防設備複查缺失未改善卻因私交未開單、登載已改善 → 圖利罪＋登載不實，非便民。

圖利罪常見實例：未依招標程序違法決標／洩漏底價便利得標／高價購買圖利廠商／監工放水／偷工減料違法驗收／對不合規定申請案違法准許／違法補助或減免稅費／違法減少裁罰金額／曲解法令圖利／違法行使裁量權。

廢弛職務釀成災害罪／洩漏國防以外秘密罪

廢弛職務釀成災害罪刑§130：廢弛職務（未盡應盡職責）致釀成災害者，處3年以上10年以下有期徒刑。限故意犯，過失廢弛職務僅生行政責任，不構成本罪。

洩漏秘密罪刑§132刑度
公務員故意洩漏交付國防以外應秘密文書圖畫消息物品（Ⅰ）3年以下有期徒刑
因過失犯前項（Ⅱ）1年以下有期徒刑、拘役或罰金（本罪為少數處罰過失之瀆職罪）
非公務員因職務業務知悉持有而洩漏交付（Ⅲ）1年以下有期徒刑、拘役或罰金
案例速記：颱風前不修堤防釀成水患 → 廢弛職務釀成災害罪。開標前洩漏底價給廠商 → 洩漏國防以外秘密罪。

公務員貪污瀆職罪以外之特別犯罪

罪名條文要點
貪污罪被告不說明財產來源罪貪§6-1檢察官偵查中，公務員本人/配偶/未成年子女涉嫌犯罪時及後3年內財產增加與收入顯不相當，命說明來源，未說明/無法合理說明/說明不實者，處5年以下有期徒刑、拘役或罰金；舉證責任轉換由被告負擔；僅限偵查中適用
行賄罪貪§11違背職務行賄：1-7年，併科300萬元以下／不違背職務行賄：3年以下，併科50萬元以下／對外國大陸港澳公務員跨境商業行賄比照辦理／自首免除其刑，偵審中自白減輕或免除
贓物罪貪§15明知因貪§4-6之罪所得財物，故為收受、搬運、隱匿、寄藏或故買者，1-7年，併科300萬元以下
誣告罪貪§16誣告他人犯本條例之罪者，依刑法加重其刑至1/2；意圖使人受刑事處分虛構事實而為自首者，3-10年
貪§11不違背職務行賄罪是100年新增，宗旨在杜絕「收錢有罪、送錢沒事」，落實「不必送、不能送、不能貪、不會貪」。

減免罪責與犯罪所得

減免罪責事由貪§8（限犯貪§4-6之罪） 📌 113年考過：

情形效果
犯罪後自首＋自動繳交全部所得減輕或免除其刑
自首＋因而查獲其他正犯或共犯（污點證人）免除其刑
偵查中自白＋自動繳交全部所得減輕其刑
偵查中自白＋因而查獲其他正犯或共犯減輕或免除其刑
口訣：自首等級最高，能到「免除」；自白次之，頂多「減輕」；只要多做到「查獲同夥」就能再往上加碼一級！（刑§62一般自首僅得減輕其刑，須留意與貪污條例特別規定之差異）
113年考古題：消防小隊長甲收賄後於偵查中坦承並繳回款項 → 對應表中第3列「偵查中自白＋自動繳交全部所得」→ 效果為減輕其刑（不是免除，也不是自首那一列，作答時對號入座別跳格）。

情節輕微減刑貪§12：犯貪§4-6之罪，所得或所圖得財物或不正利益在新臺幣5萬元以下，情節輕微者，減輕其刑；行賄罪（貪§11Ⅰ-Ⅳ）情節輕微、行求期約交付財物在5萬元以下者亦同。

犯罪所得推定貪§10：犯貪§4-6之罪，本人及配偶未成年子女自犯罪時及後3年內取得之來源可疑財產，經檢察官或法院命證明來源合法而未能證明者，視為犯罪所得（得沒收）。

玖

結語

公務員應保持廉潔操守，克盡職務本分，建立正確法律觀念：知法守法、勇於任事，方能避免觸犯法網，提升行政效能與服務品質。課程主軸：不必貪（增進正確法律觀念）、不能貪（知法守法勇於任事）、不敢貪（提升行政效能服務品質）、不願貪（提升廉能與法治素養）。

拾

案例解析速記

案例一：採購驗收不實、收賄行為

鎮公所採購電磁爐案，A公司欲改以低劣品交貨，董事長乙藉承辦人甲娶媳婦致贈10萬元紅包，甲明知驗收不符規定仍不實登載驗收合格，陳請不知情鎮長批示並付款。

解析：10萬元雖名為結婚賀禮，但金額不合社會相當性且與驗收職務有對價關係 → 屬賄賂非餽贈。甲：不應為而為（驗收不實仍通過）→ 違背職務受賄罪（貪§4Ⅰ⑤）＋公務員登載不實文書罪（刑§213），數罪併罰。乙：不具公務員身分行賄 → 非公務員對於公務員違背職務行為交付賄賂罪（貪§11Ⅳ準用Ⅰ）。

案例二：公務員主動辦理災害救助（圖利 vs 便民）

甲因颱風房屋受損，縣府承辦人乙為其好友，主動為甲辦理災害救助。問乙之行為係圖利或便民？

解析：關鍵在「是否符合《社會救助法》§25致損害重大影響生活之要件」。若確已符合要件：乙主動辦理未違背法令、甲所得非不法利益 → 便民。若未達要件仍辦理：違背法令且使甲得不法利益 → 圖利罪（貪§6Ⅰ④）。「致損害重大」屬不確定法律概念，公務員有判斷餘地，但仍須妥當合法判斷，不得恣意濫用或圖特定人私益。
