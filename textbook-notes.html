公共政策的概念

一、公共政策循環的概念

公共政策：政府有關機關為解決某項公共問題或滿足某項公眾需求，決定作為或不作為，以及如何作為的相關活動（吳定，1999：357）。

階段論者認為，政策問題一旦形成並進入政府制度議程後，便會依序進行政策規劃、合法化、執行與評估等階段（李衍儒、趙永茂，2016：10）。

政策過程一般分為五大階段（賴維堯，1994：61；林水波、張世賢，2006：50-56）：

  • （一）問題認定：決策者面對決策情境時，首先須釐清所面對的真正問題及其根本原因，才能對症下藥、有效解決問題。
  • （二）政策規劃：政策問題一經認定後，承辦人（單位）就要規劃出可行的行動方案，以解決當下政策問題。
  • （三）政策採用（亦即政策合法化）：行動方案擬定完成後，尚須經由具法定權限的機關（如立法機關）依一定程序審議並核定，使政策獲得合法地位，表示正式同意採用該行動方案。
  • （四）政策執行：政策採用後，負責執行的機關會組織所需資源、動員人力，透過適當管理手段推動政策。
  • （五）政策評估：以系統性與客觀的資料蒐集方法，分析政策執行過程與成效，藉此掌握政策運作實況，作為未來政策持續、修正或終結的依據。

資料來源：參考自 Anderson（1984: 19-20）。

二、公共政策的類型

Lowi（1972）與 Salisbury（1968）認為政策可依據「對社會的影響」，區分為4種類型（丘昌泰，2008：11-13）：

類型英文說明例子
管制性政策regulatory policy權威當局設定一致性管制規則或規範，指導政府機關/標的團體採取某些行動交通管制、碳排放管制
自我管制政策self-regulatory policy權威當局未設嚴格一致規則，僅設原則性規範，委由各機關/團體自行決定，干涉程度較低社區自治、大學自治
重分配政策redistributive policy將某一標的團體的利益或義務，轉嫁給另一標的團體享受或承擔所得稅累進稅率
分配性政策distributive policy將利益或義務分配給不同政府機關或標的團體享受或承擔財政補助

三、方案管理的意義與步驟

（一）公共方案的意義

《公共政策辭典》引述 Grover Starling（1988）於《政策制訂策略》書中分析：政策（policy）、計畫（plan）、方案（program）與行動（action）在層次上有差異，政策層次最高，其次為計畫，再者為方案，最下層為行動。

計畫為執行政策的一組具體措施；方案則為達成目標之特定行動，與一般管理領域「專案管理」中的專案 project屬同一層次。

所謂公共方案 public program是政府機關為解決公共問題，所採取的一組積極作為或消極不作為的有限理性選擇與行動。

資料來源：參考自 Starling（1988: 1-3）。

（二）方案管理的意義

方案管理係指一套有系統的方案規劃方法、執行的行動步驟與績效評核方式，包括：瞭解與分析政策問題、釐清標的人口的需求、確定政策目標及規劃方案內容等，提出可行的公共方案，方案依規劃內容推動與執行，並運用可操作的方案管理方法，進行管考與績效評核。

方案管理可分為 確認問題、瞭解需求、設定目標、發展方案、執行方案、評估方案 等6個主要步驟，各步驟之間具有前後連貫的關係，最終方案結果也將作為檢驗問題是否真正獲得解決。

方案問題分析

一、方案問題認定

學者杜威（J. Dewey）指出：「界定出一個好的問題等於是解決了一半的問題。」分析或界定方案問題時，可參考下列原則：

  • （一）說明方案情境或現況事實的存在與趨勢
  • （二）因為這個方案的情境或事實的存在，而可能導致的問題與負面後果
  • （三）界定這個方案的問題核心

方案問題主要包含三項要素：

  1. 問題（problem）：通常指事件對個人或社會之威脅或影響的深度與廣度，而政策問題則是指一種尚未被實現的需求、價值或機會，希望透過公共行動來加以實現或改善。
  2. 機會（opportunity）：指問題是否有改善的可能，但並非所有社會問題皆存在機會，若不存在或改善的成本大於效益，則該問題可能當下並不值得積極採取行動。
  3. 趨勢（trend）：是一種關於問題未來演變走向和波動幅度的判斷，問題常隱藏在趨勢之中，若決策欠缺宏觀透視力與洞察力，則可能無法看清問題真貌而錯失有效解決或避免問題的先機。

二、方案之「標的人口」與「利害關係人」

在進行整體方案規劃前，必須先釐清標的人口與利害關係人，以確保方案的規劃與執行能夠回應實際需求，並兼顧不同群體的利益與觀點。當能夠在方案規劃初期就將不同利害關係人納入，所發展出的方案才能確實回應他們的需求，也就是一般常說的「接地氣」。

標的人口：指因方案之執行而直接受影響之個人或團體，例如：長照政策中的照顧管理人員。

利害關係人：指所有能影響某項政策方案或受到某項政策方案影響的人員（同時包含直接或間接、有形或無形、正面或負面）。「標的人口」也是對利害關係人的稱呼之一，但「利害關係人」所涵蓋的範圍比標的人口更為廣泛與全面。

三、利害關係人分析方法

（一）政策利害關係人分析（policy stakeholder analysis）

Dunn（2012）指出，政府在制定政策時，必須重視政策利害關係人的意見與態度，方能制定符合公平正義原則的政策。利害關係人主要可分為三大類：

  • 政策制定者：直接制定、規劃及執行政策的個人或團體
  • 政策受益者：政策制定過程中直接或間接獲得利益的個人或團體
  • 政策犧牲者：政策制定過程中利益受到侵害或損失的個人或團體

資料來源：郭瑞坤、賴正能、廖英賢（2006：40）。

（二）權力與利益矩陣分析（Power & Interest Grid Analysis）

Eden 與 Ackermann（1998）根據權力大小及利害相關性高低，將利害關係人分成4個類別，並進行2x2矩陣的排序：

  1. 主要利害關係人：利害相關性高且權力大
  2. 次要利害關係人：利害相關性高但權力較小
  3. 系絡制定者：權力大但利害相關性較低
  4. 一般大眾：利害相關性較低且權力較小

資料來源：Eden & Ackermann（1998）。

四、循證決策與需求分析

（一）循證決策

「循證」（evidence-based）強調透過嚴謹且具系統性的方法來獲取證據，而非依據個人主觀經驗（吳寂絹、卜小蝶，2015）。傳統的政策制定模式多依循過往經驗、社會價值、民眾意見或政黨理念，但未必符合當下情況，也經常可能因缺乏對現實的瞭解，導致部分政策未能如預期達成目標，甚至帶來非預期的負面效果（莊文忠，2018）。

近來各國積極推動「循證決策」（evidence-based decision-making），強調以證據為基礎來做出決策，政策制定者應運用研究分析而得的最佳證據，作為政策形成的核心，是一種有別於以直覺、主觀或意識形態等意見基礎的決策方式（李文德，2021；廖洲棚，2024）。這種決策機制能降低決策的不確定性，幫助政府制定出更高品質的政策。

（二）需求分析

為實踐循證決策，政策制定者需掌握不同利害關係人的實際需求，作為問題界定與方案設計的依據。常見方法：

  1. 民意調查或訪談：直接經由調查或訪談，詢問利害關係人的感受與需求程度
  2. 運用實驗性方案檢視需求：規劃小型實驗性方案，經由小群體參與觀察需求
  3. 民意機關提案反映需求：民意機關對特定公共議題不斷提出政策規劃，是對民意需求最直接的反應
  4. 運用實證研究及調查結果分析需求：實證研究結果、研究分析報告、統計調查、輿情分析等

關鍵洞察：
  1. 方案管理是7年來唯一每年都考的科目，而且永遠是第一題、分數最高（25～50分不等，通常30分）
  2. 考的「工具」會輪替，不會每年重複同一種：6W2H1E考過4次（108,109,110,112）、SWOT考過2次（111,114）、TOWS考過1次（114，且是接續SWOT一起考）、魚骨圖考過2次（109只考向左；113年向右+向左都考）
  3. 情境題材偏好：新設備/新方案是否推動（SWOT/TOWS類）、活動安全管理計畫（6W2H1E類）、找原因+找對策（魚骨圖類）
  4. 結論：四種工具（6W2H1E、SWOT、TOWS、魚骨圖）都必須熟練到能直接上手默寫，不能只準備其中一種，因為出題老師顯然是刻意輪替出題、避免連續兩年重複同一工具

一、向右魚骨圖：確認問題並盤點問題原因 📌113年考過

（一）方法說明：根據石川馨博士發展出的特性要因分析圖，因其繪製出的外型與魚骨相似，故又稱魚骨圖，用於問題分析的魚骨圖為向右魚骨圖。

（二）分析步驟：問題癥結 ← 大要因 ← 小要因

  • 1. 問題癥結：向右魚骨圖最右端標註為主要面臨的問題癥結（problem），意指實際存在的困難或挑戰，應以肯定句呈現被定義清楚的問題癥結，而非一般提問的問題（question）形式。
    ✔ 問題癥結（problem）：長照2.0照管人力不足　　✘ 問題（question）：為什麼照管人力會不足？
  • 2. 大要因：造成問題癥結的主要原因或面向，需先透過討論與歸納，找出幾個主要原因
  • 3. 小要因：在大要因之下，進一步找出更具體、可操作的原因，可透過腦力激盪法（brainstorming）逐一列舉
Q：分析問題癥結時，一定先「大要因」嗎？
A：不一定，可視實務操作調整。也可以先在魚骨圖右端確認清楚問題，腦力激盪列出小要因，再把小要因整理成大要因，這樣既能抓住細節也能看到問題全貌。

（三）運用說明：

  • 各項小要因未必能完全獨立，需注意小要因彼此之間互相牽連的關係
  • 魚骨圖上看不出各項小要因何者重要、何者次要，實務運用要留意重要性程度，以優先呈現相對重要者為主
  • 描述大要因與小要因時，建議以具體、明確的「形容詞語句」進行描述，例如「程序繁瑣」、「人力不足」、「工時過長」等

二、向左魚骨圖：設定目標並發展替選方案 📌109,113年考過

方案目標訂定後，需提出適當的行動方案以達成目標，但達成目標可能有各種不同策略，故須發展各種可行的策略，稱之為「替選方案 alternatives」。

（一）方法說明：「向左魚骨圖」是對應於「向右魚骨圖」的問題癥結，提出的可能解決方案。

（二）分析步驟：設定目標 → 方案產出 → 對策擬定

  • 1. 問題解決的策略或目標：向左魚骨圖最左端標註為問題解決的策略或目標
  • 2. 可能解決問題的方案：可利用腦力激盪法進行小組討論，找出解決對應問題的解決方案
  • 3. 解決方案下的可行對策：針對解決方案下的各細項，找出可行對策

（三）運用說明：可運用創新思維，突破過去傳統思維框架，提出更有效的解決方案。描述解決方案及可行對策時，建議以具體、明確的「動詞語句」進行描述，例如「簡化程序」、「增加人力」、「降低工時」等。

「向右魚骨圖」與「向左魚骨圖」通常是配套使用的工具。前者有助於系統性地釐清政策問題的成因與脈絡，後者則用於探索可能的對策與方案，兩者結合能更完整地掌握問題全貌及提出具體可行的解決策略。

三、決策矩陣分析：篩選最終替選方案 尚未單獨出過題，但仍為完整流程一環

已透過「向左魚骨圖」提出初步多種可能解決方案，但在時間與預算等資源有限情況下，可能無法全部實施，須找出較佳可行方案優先執行。此時可利用「決策矩陣分析法」、可行性分析、成本效益分析或決策樹等方法，來協助篩選出最終方案。

決策矩陣分析程序：

  1. 羅列各種可行的對策：列出向左魚骨圖找出的各種問題解決可行對策
  2. 訂定各種衡量指標，並決定其相對重要性（權重）：依問題原因列出所有決策指標，指標間須相互獨立，例如行政、財務、技術、創新、時間及效益等，並訂出各指標權重百分比
  3. 針對可行對策予以評分：依每個指標，針對所有方案給予評分，如「1分至3分」或「1分至5分」，代表該對策在該指標上從非常不利到非常有利的評價
  4. 計算加權總分：計算每個可行對策在所有指標上的加權總分（權重乘以評分）
  5. 排列出可行對策的優先順序：依加權總分高低排定優先順序，總分最高者列為優先可行對策；亦可修正評分或權重，甚至產生更多可行對策，直到找出最佳對策為止

實務運作上，決策矩陣分析亦可能不會實際操作出來，例如長官判斷後直接決定做法。然而，若將長官決策過程加以分析，仍常可發現其思維邏輯高度契合決策矩陣的內涵與方式，可作為多方案選擇的事前分析，提供長官決策參考。當長官對各項指標的權重有不同想法時，可能就會改變方案選擇的排序。

四、可行性分析：評估替選方案 尚未單獨出過題，但仍為完整流程一環

可行性分析 feasibility analysis是通過對各種行政、技術、資源、人力的經濟合理性分析，選擇以最小的人力、物力、財力耗費，取得最佳技術、經濟、社會效益的解決方案。

在羅列出政策替選方案後，除可使用決策矩陣決定方案外，也可利用可行性分析評估方案在不同面向的可行性，常見4項面向：

  1. 政治可行性分析：評估權責機關首長、執政黨、議會多數，以及其他關鍵利害關係人對該方案的支持度及反對力道
  2. 經濟或技術可行性：評估成本效益之大小及技術上是否存在可行性
  3. 行政或法律可行性：評估執行上是否有窒礙難行之處，或法律上是否有明文禁止
  4. 社會或環境可行性：考慮實施方案所處環境的社會氛圍，有無與當地文化產生扞格

（二）不可行因應措施：若方案被判定為不可行或與當地文化、社會環境產生扞格，可考慮以下因應措施：

  1. 調整現行方案：根據可行性分析結果，對方案進行必要調整，以克服政治、經濟或文化上的障礙。例如擴大進行「需求評估」瞭解不同利害關係人期望，並據此調整方案找出最大公約數
  2. 提出替代方案：考量不同政治、經濟或社會條件，提出其他可行替代方案，以繼續推動政策實施
  3. 利益協商：為克服政治或文化上的阻礙，透過多方協商討論尋求妥協或達成共識，避免強行推動引發衝突或抵制
  4. 逐步實施：在社會或文化層面有扞格的情況下，選擇逐步實施方案，從較易接受的部分開始，後期逐步推進
  5. 訂定日出（落）條款：當遇到影響較為重大的方案或政策時，明確給予開始實施（或結束）的時間點，並給予合理緩衝期，讓利害關係人有所準備與因應
判斷準則：多方案選一 → 用「決策矩陣分析」；單一方案評估執行可行性 → 用「可行性分析」，可視情況判斷使用時機。

五、SWOT分析：診斷替選方案內容 📌111,114年考過

SWOT分析法係於80年代初由美國舊金山大學管理學教授韋里克（Weihrich）提出，經常用於企業策略制定及競爭對手分析等場合。SWOT分析是對組織或特定方案內外部條件進行綜合及概括，進而分析其優劣勢、面臨的機會和威脅的一種方法。透過SWOT分析，可將特定方案的資源和行動聚集在自己的強項和最多機會的地方，讓方案策略更加明朗。

（一）概念說明：SWOT分別為 Strength（優勢）、Weakness（劣勢）、Opportunity（機會）、Threat（威脅）4個英文字縮寫，指推動特定方案時應盤點「機關內部本身的優勢和劣勢」及「外部環境帶來的機會和威脅」。

內部因素通常包括：人力、組織、經費、整合、協調、領導、執行力等；外部環境可從 TEMPLES 角度討論：科技Technology、經濟Economy、媒體Media、政治Politics、法律Law、環境Environment、社會Society。

（二）分析步驟：

  1. 盤點組織內部的優勢與劣勢
  2. 確認組織面對的外部環境
  3. 盤點影響組織的外部因素，包含機會與威脅

六、TOWS分析：研擬可行策略 📌114年考過(接續SWOT)

進行完SWOT分析後，緊接著運用TOWS分析進行可行策略的研擬。SWOT分析主要用於盤點政策或方案的內外部條件，整理出優勢、劣勢、機會與威脅；TOWS分析則以SWOT分析結果為基礎，發展具體可行的策略建議。實務運用上通常先進行SWOT分析，再透過TOWS分析將優勢、劣勢、機會與威脅4項因素交叉配對，得出4種策略：

策略條件做法
SO 進攻策略利用外在機會＋本身優勢積極創造利基，將優勢與機會最大化
ST 補強策略擁有優勢，但受限於外在威脅利用有利條件排除外在環境的衝擊或障礙
WO 轉型策略把握外在機會＋降低本身劣勢轉變或降低組織本身的劣勢
WT 防禦策略本身劣勢＋外在環境不利至少不使情勢繼續惡化，將威脅與劣勢影響降至最低

舉例：主管機關通常具有專業能力與資源，機關首長多半願意支持政策，當社會高度關注、合作意願高時，適合採取推動公私協力、建立跨部門平台等「SO進攻策略」。若機關具備專業與公權力，但社會大眾不願配合或信任感低，可採「ST補強策略」加強政策溝通或導入第三方評估機制。若機關本身人力缺乏，可整合外部資源，採「WO轉型策略」。若自身條件不利、外在抗拒或風險大，則應採「WT防禦策略」，以階段性或試辦性措施保守為之。

SWOT用「形容詞之語句」描述狀況/特性/條件（如「行政程序繁瑣」）；TOWS用「動詞之語句」表示可以做什麼（如「推動公私協力計畫」）。

七、成本效益分析與成本效果分析：評估預期結果 尚未單獨出過題，但仍為完整流程一環

（一）成本效益分析（Cost-Benefit Analysis, CBA）：將政策方案所需的成本及預期可獲得的利益轉換成貨幣單位，用來判斷政策方案是否採行的分析工具。進行時通常也需考量成本與利益的外部性與機會成本。

首先列出所有成本與利益並轉換成貨幣，進而比較成本與利益間的關係，例如益本比（利益淨值／成本淨值）或淨現值（利益淨值−成本淨值）。當益本比大於1或淨現值大於0時，該方案即值得採行。

（二）成本效果分析（Cost-Effectiveness Analysis, CEA）：是從許多替代方案中，抉擇最適計畫的方法之一，屬於成本效益分析的一種變化形式。當效益未必能夠輕易轉換成貨幣價值時，可直接以方案能夠達成的「目標」作為最終結果，也就是「效果」。羅列出所有方案能達成的「效果」後，即可根據其成本，從不同方案中選出能以最小成本達成最大效果的方案。然而效果與成本衡量單位不同，無法協助規劃者判斷「某項計畫是否應該執行」的問題，最終只能用「價值判斷」來做為決策依據。

八、決策樹法：判斷方案期望值 尚未單獨出過題，但仍為完整流程一環

「決策樹法」主要用在決策過程可能面臨「風險 risk」或「不確定性 uncertainty」的情況。使用時需列出決策點（問題）的各種可能方案，以及方案出現的機率值與報酬，據以計算每一方案的「期望值」，協助選出「最有利對策」，步驟如下：

  1. 繪製樹狀圖：根據已知條件列出各種方案；決策樹繪製由左至右進行，以「決策點」表示可選方案
  2. 列出機率與報酬：完成決策樹結構後，評估並標示各方案可能情境的發生機率與對應報酬。機率可採「客觀機率」或「主觀機率」，視情境而定；報酬應以一致單位衡量（如新臺幣元）
  3. 計算期望值：將各情況發生的機率乘以方案報酬，得出決策的「期望值」，並標示於對應狀態節點
  4. 比較期望值：依期望值大小比較方案，選出最高者即為最佳方案

九、甘特圖與查核點：掌控及管制方案執行情形 尚未單獨出過題，但仍為完整流程一環

（一）甘特圖（Gantt Chart）：繪製目的在於方案規劃時，能預先有全面且完整的推演，並藉以掌控流程進度，作為方案執行時之依據與檢視。繪製方式：橫軸表示時間，縱軸表示活動或工作項目，每項工作項目需執行時限則以條狀圖呈現，下方可顯示完成百分比。

（二）查核點設計：查核點（check points）是指方案流程中可以進行查核的點，以利執行部門或研考部門確實掌握、管制方案執行情形。可依循甘特圖時程表建立查核點，並根據預定時程表示方案完成進度（如：10%、20%、20-75%、70-90%、95%、100%等目標值），查核結果分為：通過／有條件通過／查核已完成改善／查核待改善事項／查核不通過。

Q：撰擬政策報告時，政策工具全部要用嗎？
A：應依據不同的政策議題與分析目的，選擇最能協助釐清問題、篩選方案的工具加以運用，而非將所有可用工具一併使用，以避免流於形式或過度堆砌，適度且精準地運用分析工具，才能使政策方案更具說服力與可行性。

方案目標訂定與達成

一、目標設定原則：SMART原則

學理上，「目標」（goal）係指對未來期望情境之價值性陳述；「目的」（objective）則為具體且可操作化之描述。雖然目的為目標的具體展現，惟於實務運作上兩者常被混用，並無嚴格區分。目標的設定須與機關職掌及組織任務相契合，除配合公共方案問題分析與利害關係人需求外，亦應符合SMART原則。

原則說明案例（規劃舉辦政策說明會）
簡單且明確
Simple & specific		目標應簡單、明確、易懂且有彈性規劃舉辦5場政策說明會
可衡量性
Measurable		目標應可被具體衡量每場參與人數至少達50人
可達成性
Achievable		目標應具挑戰性，但仍在可達成範圍內避免設「完全杜絕交通違規」等不切實際目標
應與結果有關
Result-orient/relevant		目標須以結果為導向，並與績效具關聯性主目標（提升推廣成效）與次目標（辦說明會、媒體宣導）須相互支持
時限性
Timely		目標應明確訂定完成期限1年內完成5場說明會並完成評估報告

二、標竿學習 benchmarking

（一）概念：標竿（benchmarking）原意為「固定對象的標記，諸如用石柱來說明高出海平面之高度，作為調查中的參考點」，有基準之意，構想是尋找學習的對象，以其既有成就為基準。例如：以其他表現優異縣市的觀光客到訪率為基準進行方案規劃；或以國外類同方案目標為參考基準；或參考其他國家資源回收處理率，訂定垃圾處理方案的目標。

（二）應兼顧務實目標：標竿學習可作為特定方案設定目標的工具，但過程應有適切的專案討論，有系統蒐集資訊並分析，設定量化可衡量的目標，需符合推動方案的需求，避免太過理想、不切實際。參考傑出標竿鎖定的目標，能夠激勵方案設計者與執行者不斷努力改善，加速提升達成目標與績效。

三、方案工具（Schneider & Ingram, 1990）

方案目標的達成程度，經常取決於是否有選擇合適的方案工具，Howlett將方案工具界定為「政府執行公共政策目標時可以使用的技術或方法」。實務上方案工具可分為5大類型：

  1. 權威式（authority）方案工具：政府以合法權威採取強制或管制手段。例：闖紅燈者被開罰單，或以累進稅率對富人課以較高稅額
  2. 誘因式（incentive）方案工具：以正面或負面經濟誘因來激勵誘導人口順服。例：發放消費券以鼓勵民眾多消費，達成提升經濟成長的政策目標
  3. 能力建立型（capacity）方案工具：提供資訊或訓練，使其擁有能力做決策或從事活動。例：舉辦公聽會，說明都市更新的相關政策措施，或讓民眾參與都市更新的規劃過程
  4. 符號與勸戒型（symbolic and hortatory）方案工具：行為者以其自身信仰與價值作為判斷基礎，透過形象、符號或非實體性價值來改變標的人口的政策偏好認知。例：食品GMP微笑標章，即為食品安全的符號
  5. 學習型（learning）方案工具：當問題不確定且對於應採取行動也缺乏瞭解時，可採取學習型方案工具。例：疫情期間政府主動教導民眾如何正確配戴口罩

就方案內容而言，嚇阻、懲罰及權威等屬於「管制類」方案工具，而誘因、符號與勸戒、能力建構與學習等屬於「誘導類」方案工具。不同工具可適用於各種不同政策領域，彼此也沒有孰優孰劣的強烈區分，端視主觀假定與客觀工具是否能契合而定。

方案計畫書之撰寫

一、6W2H1E 📌108,109,110,112年考過・考古最大宗

透過各種分析方法發展出可行對策後，需將其綜整為具體的執行方案，為確保方案規劃內容周全，可運用6W2H1E的概念作為呈現時的參考依據。方案計畫書之內容可以從9個基本要項進行說明：

構面說明
Why 為什麼方案推動之緣由（待改善的焦點）及現況情境分析
What 什麼方案的目標、重要規劃之內容
How 如何方案如何推動與實施方式。說明方案的「主要內容」由「誰」、「在何時」或「何處」、「用何種適當的方法」推動方案
Who 誰方案的規劃與推動者，主、協辦單位
Whom 對誰方案的實施對象，亦即受到方案影響的人
Where 何處方案影響的空間範圍，如區位與交通動線；或方案執行地點
When 何時方案執行的期程，可為年度計畫或中長程計畫，可用甘特圖與查核點執行進度管制
How much 多少方案之預算規劃及財務營運計畫
Effect 效果方案推動後之預期績效及可能之負面效果

二、績效指標訂定（KPI vs. CPI）與方案成果評估

（一）績效指標訂定：方案績效指標一般分為「關鍵績效指標」與「共同績效指標」。

  1. 關鍵績效指標（Key Performance Indicator, KPI）：當特定方案執行完成後，所希望達成與方案最直接相關的目標或效益，通常運用SMART原則訂定目標，以確保KPI指標具備明確性、可衡量性、可達成性、相關性和時限性。例如觀光客倍增計畫中訂定「每年度應增加10%的觀光客人數」；或某項政策活動設定「媒體與社群平台之曝光觸及數應達3,000次」等。
  2. 共同績效指標（Common Performance Indicator, CPI）：指每項計畫執行過程中都可能出現的相類似評比項目，例如計畫進行進度、預算執行率或資料處理即時性等。

（二）執行成效評估：行政人員應將監督評估結果，提供管理階層作為決策參考，以決定何時該採取行動、何時不須採取行動，並查看目標是否已達成、是否還有需要改進之處。

  • 目標未達成 → 須回到原因分析階段重新開始
  • 方案對策無效 → 進一步探討是否係執行不力，並回到問題分析階段重新分析
  • 目標已達成 → 將解決方案標準化，融入日常作業，以防止問題再現

為使評估準確測量執行內容，規劃階段應具邏輯一致性與明確優先順序，執行階段則應有完整詳實紀錄，以檢核方案是否確實有效解決問題。因此 6W2H1E、甘特圖、查核點、KPI與CPI 的確實執行，將有助於評估與決策的參考。

方案評估有時難以用理性模型解釋，可能是不同價值間妥協後的產物，須注意評估主觀性、評估者立場、評估標準的選擇及環境變遷等影響，以降低評估失準之風險。

案例解析：長照2.0照管人力不足

一、情境敘述

假定您是衛生福利部（衛福部）長期照顧司的業務承辦人，負責照顧管理制度的規劃。近年來「長期照顧十年計畫2.0」（長照2.0）政策正面臨照管人力不足的問題，需運用前述政策分析工具及概念，發展出有效且可行的政策方案。

我國政府為因應高齡化社會，自2016年推動長照2.0，整合衛政、社政、醫療、非營利組織等公私部門資源，提供長期照顧服務。相較於長照1.0，長照2.0擴大服務對象、增添服務項目，並以各縣市長期照顧管理中心（照管中心）為服務樞紐：民眾申請後由照管專員諮詢評估，資格符合者派案給A級單位（社區整合型服務中心）的個管員擬定照顧服務計畫，再轉介B、C級單位提供服務，個管員定期追蹤複評；不符資格者協助轉介其他民間資源。

A級單位：社區整合型服務中心（個管員與照管專員擬定照顧計畫、資源連結協調）；B級單位：複合型服務中心（居家服務、日間照顧、交通接送、喘息服務）；C級單位：巷弄長照站（臨托、餐飲、前端預防等）。（衛生福利部，2016：87-89）

各縣市照管中心多為任務編組，非正式單位，人力多為臨時約聘人員。依「長照2.0計畫核定本」，服務量每150案至200案配置照管專員1名，每5至7位照管專員設督導1名。惟自2019年起，照管人員平均服務案量皆遠高於標準，人力增加速度遠跟不上需求提高的速度（黃彥斌，2019）。

二、方案設計的方法（九步驟完整流程）

（一）向右魚骨圖：確認問題並盤點問題原因

歸納出造成長照2.0照管人力不足的4項主要原因：

  1. 任用資格門檻較高：需具備特定學歷、專業證照及相關工作經驗（依《長照人員訓練辦法》第2條第2項規定），限制潛在求職者範圍
  2. 工作內容負荷較重：屬高情緒勞務職業，服務案量均超過200案，加班已成常態，且與個管員分工不明確，職責混淆
  3. 薪資競爭力較低：照管專員相當薦任第6至7職等，起薪43,399元、最高56,752元，雖需2至5年工作經驗，起薪卻與普考及格人員（免經驗要求）相當，且無明文調薪機制
  4. 工作穩定性不佳：屬約聘僱人員，一年一聘，升遷機會有限，且政策常滾動式修正，第一線人員缺乏緩衝準備期

資料來源：董祥開整理（2025）。

結語

方案管理的課程，主要是在建立政策規劃人員「系統思考」之能力，並依據政策方案的規劃步驟，針對特定問題加以解決。其次，希望能夠訓練政策規劃人員在提出方案的過程中，懂得如何運用合適的方案規劃技術與方法，搭配不同利害關係人的需求，規劃出更接地氣、更有效益的政策方案。

特別是，當要定義政策問題時，懂得能夠先進行「特性要因分析」，繪製向右魚骨圖來找出造成問題的原因；接續訂定方案目標，繪製向左魚骨圖來研擬問題的解決方案。此外，在發展方案時，能夠正確地使用不同的政策分析工具，例如：「可行性分析」、「決策矩陣分析」、「SWOT分析」、「利害關係人分析」、「成本效益分析」、「決策樹」或「甘特圖」等來進行分析。最終，期待受訓人員能夠以一套有系統的方式（6W2H1E）來完整呈現方案計畫書。

本堂課程所教授的內容，屬於高度「應用性的知識（applied knowledge）」，希望受訓人員在未來的公務生涯中逐步升遷、工作特性逐漸從「政策執行」層次轉變為「政策規劃」層次時，能夠有效應用本課程所介紹的概念與能力，成為合格且優秀的政策規劃人才。

延伸學習：3則自我練習案例

案例一：推動地方文化創意產業發展方案

緣起：甲區屬早期發展城市，隨產業重心移轉逐漸沒落，處於城市邊陲。甲區公所為振興當地產業，配合市政府「一區一特色」目標，指派經建課陳課員承辦，擬提出3年計畫發展地方特色文創產業。

背景：甲區早期為商業交易熱絡之地，擁有精緻洋樓建築，混合閩南式與西洋巴洛克式建築仍完整保留，惟隨產業經濟轉變已成城市邊緣，充斥老舊街道、社區、眷村，人口老化嚴重。文化部積極推動文創產業，提供補助計畫鼓勵地方政府整合資源。

思考重點：

  1. 甲區公所推動地方文創產業的問題癥結為何？形成問題的主要原因為何？
  2. 宜討論地方文創產業發展的衡量準則，例如：預算經費限制、技術可行性或創造的產值等
  3. 以陳課員角度，思考策略上應如何運作、舉辦什麼活動，結合傳統文化保存、空間規劃、歷史建築保存、增進民眾認同與創造文化價值
  4. 宜考量政府間跨域合作、產學合作、行銷推廣，吸引專業人士或透過民間企業協作方式執行

案例二：推動淨零生活的環境保護方案

緣起：氣候變遷與環境保護議題受重視，我國提出2050淨零排放策略，短期（～2030）達成低碳，長期（～2050）朝零碳發展。

背景：小謝任職於市府環境保護局，主要業務為低碳社區推廣發展，持續進行校園及社區住宅低碳認證與輔導獎勵，惟推廣過程參與低碳認證的社區數量難以有效提升，許多社區不知道或不瞭解該計畫，業務推展遇瓶頸。

思考重點：

  1. 造成低碳社區計畫推動困難的問題癥結與主要原因為何？
  2. 針對主要問題應如何對症下藥，以提升社區參與意願並有效落實低碳生活？
  3. 可思考與相關環境保護團體合作，提供專業協助，降低社區加入低碳認證的進入障礙
  4. 可透過SWOT分析思考推動策略方向，應著重在哪個環境因素上會有較大推動成效？

案例三：小鎮食品安全衛生方案

緣起：食材來源日趨多元，食品供應商為節省成本購買劣質食材或添加非法添加物，國內曾發生毒奶粉、塑化劑、毒澱粉等食安事件，引起高度關注。

背景：楊衛生稽查員任職戊鎮衛生所，負責違法黑心食品舉發，發現鎮內飲料店、炸雞排林立，曾爆發食安事件但民眾已逐漸淡忘。衛生所僅2位衛生稽查員，難以負荷全面稽查工作量，且流動攤販難以稽查；該鎮每年度食品安全預算僅編列100萬元。

思考重點：

  1. 造成戊鎮食品衛生堪慮的問題癥結與主要原因為何？
  2. 如何引入既有社會資源，協助該鎮推動食品安全方案？
  3. 宜思考引入志工或民間食安專業團體協助稽查作業，或提出檢舉獎金方案鼓勵揭發黑心食品等方案可行性
  4. 宜思考強化優勢與機會，例如與社區既有食品同業公會合作共同推動等，並應減少弱勢與威脅
